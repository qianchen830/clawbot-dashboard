# 金蝶调研汇报PPT生成器 v2.0

## 📋 功能概述

这是一个专业的金蝶调研汇报PPT生成器，能够自动生成符合金蝶项目交付标准的调研汇报演示文稿，包含15页专业内容，支持高级视觉设计（卡片布局、图表化展示）。

## ✨ 核心特性

### 1. 专业的PPT格式
- **封面**：包含公司名称、项目名称、调研日期等信息
- **目录**：清晰的章节导航
- **内容页**：专业的卡片式布局和图表化展示

### 2. 完整的15页结构

#### 第1-2页：开篇
- **封面**：项目信息展示
- **目录**：章节导航

#### 第3-4页：调研概述
- **项目背景**：项目信息、调研范围、时间轴、关键指标
- **调研方法**：访谈法、问卷法、观察法、文档法

#### 第5-7页：现状分析
- **组织架构**：组织架构图、特点、挑战、改进方向
- **业务流程**：流程现状表格、优化建议、效率提升预期
- **系统现状**：系统使用情况、问题分析、集成需求、技术建议

#### 第8-9页：痛点诊断
- **痛点清单**：6大痛点卡片展示
- **影响分析**：业务影响、管理影响、财务影响、人员影响

#### 第10-11页：需求分析
- **需求清单**：需求表格、分类统计、覆盖范围、实现路径
- **优先级排序**：评估维度、优先级矩阵

#### 第12-13页：改进建议
- **解决方案建议**：方案架构图、核心优势、预期收益
- **实施保障**：组织保障、技术保障、资源保障、风险保障

#### 第14-15页：结尾
- **下一步计划**：实施路线图、阶段计划、里程碑
- **结束页**：感谢页面

### 3. 高级视觉设计

#### 卡片布局
- 圆角矩形卡片
- 图标装饰
- 彩色边框
- 分层展示

#### 图表化展示
- 时间轴图表
- 进度条图表
- 组织架构图
- 方案架构图
- 统计表格

#### 配色方案
- **主题蓝**：#006699（专业、稳重）
- **辅助蓝**：#0099CC（科技感）
- **强调橙**：#FF9900（活力、重点）
- **成功绿**：#2E8B57（积极、正向）
- **危险红**：#DC143C（警示、痛点）

### 4. 命令行参数支持

```bash
python3 kingdee-survey-ppt-v2-generator.py \
  --company "公司名称" \
  --project "项目名称" \
  --survey-date "调研日期" \
  --scope "调研范围" \
  --pain-points "痛点列表" \
  --requirements "需求列表" \
  --output "输出路径"
```

#### 参数说明

| 参数 | 简写 | 必填 | 说明 |
|------|------|------|------|
| --company | -c | 否 | 公司名称（默认：XX公司） |
| --project | -p | 否 | 项目名称（默认：ERP项目） |
| --survey-date | -d | 否 | 调研日期（默认：当前月份） |
| --scope | -s | 否 | 调研范围，用顿号分隔 |
| --pain-points | -pp | 否 | 痛点列表，用顿号分隔 |
| --requirements | -r | 否 | 需求列表，用顿号分隔 |
| --output | -o | 否 | 输出文件路径（默认自动生成） |
| --version | -v | 否 | 显示版本信息 |
| --help | -h | 否 | 显示帮助信息 |

## 🚀 使用方法

### 基础用法

```bash
# 最简用法（使用默认参数）
python3 kingdee-survey-ppt-v2-generator.py

# 指定公司和项目
python3 kingdee-survey-ppt-v2-generator.py \
  --company "XX公司" \
  --project "ERP项目"
```

### 完整用法

```bash
# 完整参数示例
python3 kingdee-survey-ppt-v2-generator.py \
  --company "金蝶科技" \
  --project "云星空ERP实施" \
  --survey-date "2024年3月" \
  --scope "财务管理、供应链管理、制造管理、人力资源" \
  --pain-points "信息孤岛：系统间数据无法共享、流程效率低：审批环节冗长、数据质量差：数据不准确不完整" \
  --requirements "业财一体化、供应链协同、生产计划优化、移动办公" \
  --output "/path/to/output.pptx"
```

### 简写形式

```bash
# 使用简写参数
python3 kingdee-survey-ppt-v2-generator.py \
  -c "金蝶科技" \
  -p "云星空项目" \
  -d "2024年3月" \
  -s "财务管理、供应链管理" \
  -pp "信息孤岛、流程效率低" \
  -r "业财一体化、供应链协同" \
  -o "/tmp/test.pptx"
```
