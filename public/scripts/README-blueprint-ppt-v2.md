# 金蝶蓝图汇报PPT生成器 v2.0

专业的金蝶云·苍穹蓝图汇报PPT生成工具，自动生成约25-30页的高质量汇报PPT。

## 特性

✅ **专业视觉设计**
- 精美的配色方案（蓝色主题）
- 高级架构图设计
- 流程图可视化
- 时间线展示
- 卡片式布局

✅ **完整内容结构**
- 封面与目录
- 项目概述（背景、目标）
- 现状分析（现状、痛点）
- 总体设计（原则、架构、技术）
- 业务蓝图（财务、供应链、制造、人力）
- 功能设计（核心功能、特色功能）
- 集成设计（接口、数据流）
- 实施计划（阶段、时间、资源）
- 预期效果（价值、收益）
- 结束页

✅ **智能定制**
- 根据modules参数动态生成业务蓝图页面
- 支持行业知识库自动匹配
- 参数化配置公司、项目、模块等

## 安装依赖

```bash
pip install python-pptx
```

## 使用方法

### 基本用法

```bash
python3 kingdee-blueprint-ppt-v2-generator.py --company "公司名称" --project "项目名称"
```

### 完整参数

```bash
python3 kingdee-blueprint-ppt-v2-generator.py \
  --company "金蝶集团" \
  --project "数字化转型项目" \
  --modules "财务云,供应链云,制造云,人力云" \
  --architecture "云原生微服务架构" \
  --timeline "24周" \
  --output "/path/to/output.pptx"
```

### 参数说明

| 参数 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| --company | -c | 公司名称 | XX集团 |
| --project | -p | 项目名称 | 数字化转型项目 |
| --modules | -m | 业务模块（逗号分隔） | 财务云,供应链云 |
| --architecture | -a | 技术架构 | 云原生架构 |
| --timeline | -t | 项目周期 | 20周 |
| --output | -o | 输出文件路径 | ~/output/{公司}_蓝图汇报_v2.pptx |

### 支持的业务模块

- `财务云` - 财务管理模块
- `供应链云` - 供应链管理模块
- `制造云` - 生产制造模块
- `人力云` - 人力资源管理模块

## 技术架构

```
金蝶蓝图汇报PPT生成器 v2.0
├── 配色系统 (COLORS)
├── 行业知识库 (INDUSTRY_KNOWLEDGE)
├── 模块能力库 (MODULE_CAPABILITIES)
├── 实施阶段库 (IMPLEMENTATION_STAGES)
└── 生成器类 (BlueprintPPTGenerator)
    ├── add_title_slide() - 封面页
    ├── add_section_slide() - 章节页
    ├── add_content_slide() - 内容页
    ├── add_card() - 卡片
    ├── add_icon_card() - 图标卡片
    ├── add_timeline() - 时间线
    ├── add_architecture_diagram() - 架构图
    ├── add_flow_chart() - 流程图
    ├── add_table() - 表格
    └── generate_ppt() - 主生成函数
```
