# 金蝶调研纪要Word生成器 v2.0

## 功能说明

生成规范的调研会议纪要Word文档，包含完整的文档结构和专业的格式设计。

## 文档结构

1. **封面**
   - 公司名称
   - 文档标题：调研纪要
   - 副标题：金蝶云星空项目实施调研
   - 调研日期

2. **文档控制**
   - 文档基本信息（编号、版本、编制人等）
   - 修订历史记录

3. **会议基本信息**
   - 会议主题
   - 调研时间
   - 调研地点
   - 参会人员
   - 记录人

4. **调研议题**
   - 结构化议题列表
   - 议题描述
   - 关键要点

5. **讨论内容**
   - 讨论主题
   - 提出的问题
   - 答复情况
   - 备注说明

6. **结论与决策**
   - 决策事项汇总表
   - 决策结果
   - 备注说明

7. **待办事项**
   - 待办事项清单
   - 责任人
   - 完成时间
   - 状态跟踪（已完成/进行中）

8. **附件清单**
   - 附件管理列表

## 使用方法

### 基本用法

```bash
python3 kingdee-survey-minutes-v2-generator.py \
  --company "公司名称" \
  --date "2026年03月21日" \
  --location "会议室地点" \
  --attendees "参会人员" \
  --output "输出文件名.docx"
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--company` | 公司名称 | 公司名称 |
| `--date` | 调研日期 | 今天日期 |
| `--location` | 调研地点 | 会议室 |
| `--attendees` | 参会人员 | 待补充 |
| `--topics` | 调研议题（JSON格式） | 空 |
| `--actions` | 待办事项（JSON格式） | 空 |
| `--output` | 输出文件名 | 自动生成 |

## JSON格式说明

### topics 格式

```json
[
  {
    "name": "议题名称",
    "description": "议题描述（可选）",
    "key_points": ["要点1", "要点2", "要点3"]
  }
]
```

### actions 格式

```json
[
  {
    "task": "待办事项描述",
    "owner": "责任人",
    "deadline": "完成日期",
    "status": "进行中|已完成"
  }
]
```

## 文档特色

1. **专业格式**
   - 微软雅黑字体
   - 规范的标题层级
   - 统一的表格样式
   - 合理的段落间距

2. **颜色编码**
   - 蓝色主题标题
   - 不同表格使用不同颜色表头（蓝色、红色、绿色）
   - 状态颜色标识（绿色=已完成，橙色=进行中）

3. **页眉页脚**
   - 页眉显示公司名称和文档类型
   - 页脚显示页码

4. **灵活扩展**
   - 支持JSON格式参数输入
   - 可通过参数快速生成文档框架
   - 生成的Word文档可直接编辑补充
