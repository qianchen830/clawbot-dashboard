## 使用方法

### 基本用法

```bash
python3 kingdee-kickoff-ppt-v4-generator.py --company "公司名称"
```

### 完整参数

```bash
python3 kingdee-kickoff-ppt-v4-generator.py \
  --company "公司名称" \
  --project "新ERP管理系统" \
  --manager "项目经理姓名" \
  --start-date "2024-03-01" \
  --industry "制造业" \
  --modules "财务云,供应链云,制造云,人力资源云" \
  --users 100 \
  --period "6个月"
```

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--company` | ✅ | - | 客户公司名称 |
| `--project` | ❌ | `{公司名}新ERP管理系统` | 项目名称 |
| `--manager` | ❌ | 空 | 项目经理姓名 |
| `--start-date` | ❌ | 当前日期 | 启动日期（格式：YYYY-MM-DD） |
| `--industry` | ❌ | 制造业 | 行业类型 |
| `--modules` | ❌ | 财务云,供应链云,制造云 | 模块列表，逗号分隔 |
| `--users` | ❌ | 100 | 用户数 |
| `--period` | ❌ | 6个月 | 实施周期 |

## 技术细节

### 使用的母版布局

- **布局0**：封面 - 用于第1页
- **布局1**：目录、提纲 - 用于第5、9、12、15页
- **布局2**：3_白色内页 - 用于内容页（第2-4、6-8、10-11、13-26页）
- **布局3**：封底 - 用于第30页

### 配色方案

- **主色**：深蓝 (RGB: 0, 82, 147)
- **辅色**：亮蓝 (RGB: 0, 142, 212)
- **强调色**：橙色 (RGB: 255, 153, 0)
- **辅助色**：青色 (RGB: 22, 160, 133)

1. **母版路径**：确保母版文件存在于 `/mnt/d/Kingdee文档/自动化交付工具/参考文档（模板）/ppt模板/ppt母版.pptx`
