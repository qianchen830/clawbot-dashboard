# 金蝶客户化开发设计说明书生成器 v2.0

## 📋 功能概述

这是一个专业的金蝶客户化开发设计说明书Word文档生成器，能够自动生成符合金蝶项目交付标准的完整设计文档。

## ✨ 核心特性

### 1. 专业的文档格式
- **封面**：包含项目名称、客户名称、文档版本、编制日期等信息
- **文档控制页**：包含文档修订记录和文档分发记录
- **目录**：自动生成完整的章节目录
- **页眉页脚**：统一的文档格式规范

### 2. 完整的10大板块结构

#### 第一章：概述
- 项目背景
- 项目目标
- 项目范围

#### 第二章：需求分析
- 功能需求（F001-F005）
- 非功能需求（性能、安全、易用性等）

#### 第三章：系统设计
- 架构设计（分层架构、技术选型）
- 模块设计（5个核心模块）

#### 第四章：数据库设计
- 表结构设计（5张核心表）
- 字段说明（详细字段定义）
- 索引设计

#### 第五章：接口设计
- 输入输出设计（REST API）
- 数据格式定义（JSON）
- 公共参数和返回码定义

#### 第六章：功能设计
- 功能清单（10项核心功能）
- 流程设计（基础数据管理流程、业务单据处理流程）

#### 第七章：安全设计
- 权限控制（RBAC模型）
- 数据安全（加密、备份、审计）

#### 第八章：测试方案
- 测试用例（功能测试、性能测试）
- 测试数据（数据类型和数量）

#### 第九章：部署方案
- 环境要求（硬件、软件、网络）
- 部署步骤（9个详细步骤）

#### 第十章：附录
- 代码示例（C#、SQL）
- 参考文档（5份金蝶官方文档）

### 3. 命令行参数支持

```bash
python3 kingdee-dev-spec-v2-generator.py \
  --company "公司名称" \
  --project "项目名称" \
  --module "模块名称" \
  --requirements "需求描述" \
  --output "输出路径"
```

#### 参数说明

| 参数 | 简写 | 必填 | 说明 |
|------|------|------|------|
| --company | -c | 是 | 公司名称 |
| --project | -p | 是 | 项目名称 |
| --module | -m | 是 | 模块名称 |
| --requirements | -r | 否 | 需求描述 |
| --output | -o | 否 | 输出文件路径（默认自动生成） |
| --version | -v | 否 | 显示版本信息 |
| --help | -h | 否 | 显示帮助信息 |

